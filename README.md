# ☕ Morrow Coffee Landing Page

A modern, responsive, and beautifully designed landing page for a coffee brand, featuring smooth scroll-based animations and an interactive user interface.

## 🚀 Live Demo
Check out the live website here: [Morrow Coffee Live](http://morrowcoffee.thesilverblade.com)

## 🛠️ Built With
* **React** (Frontend Library)
* **Vite** (Build Tool & Dev Server)
* **CSS3 / Tailwind CSS** (Styling & Animations)
